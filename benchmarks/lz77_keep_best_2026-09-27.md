# Production LZ77 keep-best — September 27, 2026

Original opt-in implementation: [`d422bede`](https://github.com/imazen/jxl-encoder/commit/d422bede9037e6c2a7995257c87eeaa1e34f0af9).

The lossless selector compares complete affected coding units and retains
the existing encoder result as an incumbent. On the 256-square derived-f32
regressions, frymire shrinks from 60,333 to 54,222 bytes; terminal stays at
22,072 bytes. These are whole JXL file sizes, verified against retained files.

The follow-up replaces the environment opt-in with the typed strategy gate
`lossless_lz77_keep_best`. Zenjxl and Aggressive enable it; LeanFaster and
Libjxl disable it. Custom can choose explicitly. The
[paired timing report](lz77_keep_best_timing_2026-09-27.md) records measured
cost; broad corpus qualification and x86 timing remain open. This implementation
does not promise monotonic size across effort levels or solve lossy distance
targeting. The original `d422bede` changed no default or public API. The strategy
follow-up intentionally enables selection in Zenjxl/Aggressive.

## Decision and scope

`lossless_lz77_keep_best` resolves from the strategy into the lossless profile.
The obsolete `JXL_LZ77_KEEP_BEST` variable has no effect. It applies to
learned ANS backward-reference coding at effort >= 8. Strict Libjxl, lossy/ICC, explicit RLE,
Huffman, LZ77-off and faster-decoding policies keep their existing behavior.
The shared matcher retains its original acceptance threshold and sound
early-out; the former standalone ANS comparator has been removed.

`modular/lz77_keep_best.rs::Selection` constructs these final candidates:

- The incumbent: exactly the ordinary method's output, including the final
  Viterbi output when the method is Optimal.
- Plain tokens without LZ77.
- Ordinary Greedy as a separate alternative when the incumbent is Optimal.
- A three-entry bucket parse derived from post-v0.12 libjxl `e8ff0976`,
  retaining this encoder's 1 Mi-token window and 1,024-token match cap.
  This candidate bypasses estimator acceptance and is judged by coded size.

All candidates use production enhanced clustering, integer-config search,
the actual pixel hint and each section's distance multiplier. The comparison
includes LZ77 and entropy headers, tree/group/transform headers, separately
flushed ANS streams, byte padding and variable TOC cost. Constant file/frame
prefixes common to candidates are excluded. Ties keep the incumbent; writer
errors propagate. The selected tokens and built histogram are emitted together.

Single-group normal/squeezed writers reuse their final serializer for costing.
Multi-group global-tree and squeezed writers compare all streams sharing an
entropy model together. Independent local-tree sections compare their complete
padded sizes; reducing an individual section cannot increase its TOC entry.
Hybrid retains its global baseline and compares the improved local alternatives
against it. Its global/local assignment is not jointly optimized. The separate
sectioned meta-only stream is unchanged. Tree/predictor/transform selection
precedes keep-best and is not searched again.

Additional candidate token storage is reserved on the encode budget before
construction; a unit regression checks refusal before the writer runs. This is
allocation accounting, not a measured process-RSS bound. Broad memory and
runtime qualification beyond the selected timing grid remains open.

## Regression results

`modular::lz77_keep_best_tests::production_keep_best_regressions` runs the two
typed policies in separate processes. Each process sets the obsolete
environment variable to the opposite value, proving it cannot override policy. Real frymire and terminal center
crops cover 64, 256 and 259 pixels, efforts 8/9, u8/u16/derived-f32, and
global/squeezed/local/Hybrid modes. This is a selected 70-pair interaction grid,
not their full Cartesian product. Six pairs are lossy controls; 12 are strict
lossless controls. All 140 outputs fully render through jxl-rs and djxl v0.12;
all 128 lossless outputs reproduce every source sample exactly. The float
cells also check streaming in seven-row chunks: 48 additional encodes must
equal their one-shot bytes.

All 70 pairs are non-growing; 68 retain identical SHA256s. The only changed
pairs are frymire e8 f32 at 64 pixels (4,467 → 4,176 bytes) and 256 pixels
(60,333 → 54,222 bytes). All strict/lossy controls retain identical hashes.

The observer records candidate costs at the production boundary, without
influencing selection. At 256 pixels/e8 the affected coding unit excludes
59 common file/frame bytes:

| Source | Incumbent unit | Plain unit | Bucket unit | Selected whole file |
|---|---:|---:|---:|---:|
| frymire | 60,274 | 85,396 | 54,163 | 54,222 |
| terminal | 22,013 | 29,643 | 22,959 | 22,072 |

Thus terminal's unfiltered bucket output would be **23,018 bytes**. The
archived unconditional port's **29,702-byte** result was its estimator rejecting
that parse and falling back to plain tokens. Both exceed the incumbent; the
new selector retains it. The regression requires an observed rejected bucket
on terminal and an observed winning bucket on frymire, so an inactive switch
cannot satisfy it.

Unit checks cover overlapping matches, bucket eviction, distance tie order,
expired-window rejection, short tails, tie preservation, writer-error
propagation, budget refusal and TOC size-class/padding boundaries.

Mutation check: forcing selection of the bucket even when larger passes both
child decoder runs, then fails the size gate at frymire 256/e9/f32:
45,206 → 54,671 bytes. The mutation was confined to the disposable source
export and restored afterward. Logs and mutant streams remain under
`~/tmp/jxl110-keep-best-mutation/`; no expectation was relaxed.

The restored selector was rerun with `JXL_TOKEN_REUSE_OFF=1`: all 70 pairs
pass and all 140 hashes equal the accepted run. Selected global streams must
retain their chosen tokens even when this diagnostic disables ordinary token
reuse. The strengthened gate also requires exactly 70 paired rows. Evidence:
`~/tmp/jxl110-keep-best-restored/`.
The build without `parallel` also passes the complete grid and all 140 hashes
match the parallel build (`~/tmp/jxl110-keep-best-serial/`). Across these three
runs, 420 outputs receive both decoder checks and 144 additional streaming
encodes match their one-shot bytes; these repeat the same 70 configurations.

The original opt-in implementation passed the 75 existing normal/strict byte-lock and
divergence checks, 1,624 default library tests, the workspace all-target test
run (including 1,644 feature-unified encoder library tests, 508 integration
tests and 194 SIMD tests), both real-image RD gates, scoped formatting and
default workspace all-target Clippy. Existing ignores remain unchanged.
The expanded corpus-feature Clippy run is blocked by four existing
`chunks_exact_to_as_chunks` errors in `api/canonicalize.rs` (253/265) and
`tests/production_resources.rs` (96/251); these files are byte-identical to
the parent. No new-code diagnostics or lint allowances were added.
Logs are under `~/tmp/jxl-exact-cleanup/keep-best-2026-09-27/`.
The all-target command also ran the unrelated SIMD benchmark; its
[incidental output](keep_best_validation_simd_2026-09-27.log) and
[invocation](keep_best_validation_simd_2026-09-27.meta) are retained without
using those numbers to evaluate keep-best.

`jxl-encoder/tests/images/frymire-srgb.png`. The test fails on missing input.
Nightly CI provisions the corpus and v0.12 tools before invoking this gate.

```sh
CODEC_CORPUS_DIR="$HOME/Library/Caches/codec-corpus/v1" \
CARGO_TARGET_DIR="$PWD/target" \
just lz77-keep-best-check <new-label> <pinned-manifest>
```

On this Mac the pinned manifest is
`~/tmp/jxl-triage-2026-09-26/clean/siblings/jxl-encoder/Cargo.toml`; edited
encoder sources are copied into that export. It preserves the committed CI
sibling closure rather than resolving against unrelated local sibling work.
The recipe defaults to `corpus-tests,__expert,__internals,parallel` and accepts
an explicit feature-list third argument. The test uses one worker for its
thread-local observer; this is not a multithread scaling measurement.

Full logs, both arm tables, JXLs, decoded PNG/PFM outputs, decoder logs and
candidate costs are retained at `~/tmp/jxl110-keep-best-final/`.
[Paired sizes and hashes](lz77_keep_best_2026-09-27.tsv) and
